# ExScylla (lib/ex_scylla)

## Overview

The Elixir API layer of ExScylla, a thin wrapper over the Rust `scylla` driver
loaded as a Rustler NIF. `ExScylla.Native` declares the raw NIF stubs;
`ExScylla.SessionBuilder` and `ExScylla.Session` are the public entry points for
connecting and executing CQL; `ExScylla.CqlTypes` decodes CQL wire values in pure
Elixir. Subdirectories hold statement, execution-profile, load-balancing, macro,
and type modules.

## Interface

- `ExScylla.Native` (`native.ex`): `use Rustler, otp_app: :ex_scylla, crate: "ex_scylla"`.
  Declares one stub per NIF grouped by prefix: `sb_*` (SessionBuilder), `s_*`
  (Session), `q_*`, `b_*`, `ps_*` (statements), `ep_*`, `epb_*`, `eph_*`
  (execution profiles), `dp_*`, `dpb_*`, `lab_*` (load balancing). Stubs raise
  `:nif_not_loaded` (`e/0`). The retry-policy stubs `{q,b,ps}_get_retry_policy/1`,
  `q_set_retry_policy/1`, `b_set_retry_policy/2` and `ps_set_retry_policy/1` have
  the Elixir fallback body `{:error, :not_implemented_yet}` (`n/0`). The loaded Rust
  NIFs replace them and return the bare atom `:not_implemented_yet`.
  Async NIFs take the opaque term as the first argument (`sb_build/2`, `s_query/4`,
  `s_execute/4`, `s_batch/4`, `s_prepare/3`, `s_*_paged/5`, schema-agreement,
  `s_use_keyspace/4`, `s_refresh_metadata/2`, `s_get_tracing_info/3`,
  `s_prepare_batch/3`, `s_fetch_schema_version/2`).
- `ExScylla.SessionBuilder` (`session_builder.ex`, prefix `:sb`): `new/0`,
  `build/1,2` and `async_build/1,2` (returns `{:ok, T.session()} |
  {:error, NewSessionError.t()}`), and synchronous builder setters:
  `known_node/2`, `known_node_addr/2`, `known_nodes/2`, `known_nodes_addr/2`,
  `user/3`, `compression/2`, `connection_timeout/2`, `pool_size/2`,
  `default_execution_profile_handle/2`, `keyspaces_to_fetch/2`,
  `fetch_schema_metadata/2`, `disallow_shard_aware_port/2`,
  `keepalive_interval/2`, `keepalive_timeout/2`, `tcp_keepalive_interval/2`,
  `tcp_nodelay/2`, `write_coalescing/2`, `auto_schema_agreement_timeout/2`,
  `no_auto_schema_agreement/1`, `schema_agreement_interval/2`,
  `refresh_metadata_on_auto_schema_agreement/2`, `tracing_info_fetch_attempts/2`,
  `tracing_info_fetch_consistency/2`, `tracing_info_fetch_interval/2`,
  `prefer_datacenter/2`, `prefer_datacenter_and_rack/3`, `prefer_no_datacenter/1`.
- `ExScylla.Session` (`session.ex`, prefix `:s`):
  - Decoded API (sync + `async_*`): `query/3`, `query_paged/4`, `execute/3`,
    `execute_paged/4`, `batch/3` return `{:ok, QueryResult.t()}` with rows decoded
    by `QueryResult.decode/1`.
  - Raw API (sync + `async_*`): `query_raw/3`, `query_raw_paged/4`,
    `execute_raw/3`, `execute_raw_paged/4`, `batch_raw/3` return
    `{:ok, QueryResultRaw.t()}` via `QueryResult.decode_raw/1`.
  - Streams: `query_stream/3`, `execute_stream/3` (`Stream.resource/3` over the
    paged calls; yields `{:error, reason}` as the last element on failure).
  - Other async: `prepare/2`, `prepare_batch/2`, `use_keyspace/3`,
    `refresh_metadata/1`, `await_schema_agreement/1`,
    `await_timed_schema_agreement/2`, `check_schema_agreement/1`,
    `fetch_schema_version/1`, `get_tracing_info/2`.
  - Sync: `calculate_token/3`, `calculate_token_for_partition_key/4`,
    `get_cluster_state/1`, `get_default_execution_profile_handle/1`,
    `get_keyspace/1`, `get_metrics/1`.
  - Arities listed are the minimum; every sync wrapper generated by
    `native_f_async` also takes an optional trailing `timeout_ms`, and every
    `async_*` variant an optional trailing opaque term.
  - Queries accept `String.t()` or a `T.query()` reference (converted by private
    `to_scylla_query/1` to `{:string, q}` / `{:query_resource, q}`).
- `ExScylla.CqlTypes` (`cql_types.ex`): `decode_value/2` decodes a CQL value
  binary for a column type (ints, floats, boolean, text/ascii/blob, uuid/timeuuid
  as hyphenated hex strings, inet tuples, date, time, timestamp, counter, varint
  and decimal as strings, list/set as lists, map as Elixir map, tuple as tuple,
  UDT as map); unknown types return the binary unchanged.
- Subdirectories:
  - [execution](./execution/README.md) - execution profile builder, profile, handle.
  - [load_balancing](./load_balancing/README.md) - default policy and builders.
  - [macros](./macros/README.md) - `native_f`, `native_f_async`, `native_struct`.
  - [statement](./statement/README.md) - `Query`, `Prepared`, `Batch`.
  - [types](./types/README.md) - type aliases, result structs, errors.

## Invariants

- Dual-layer synchronization: each public function needs a Rust NIF in
  `native/ex_scylla/src/`, a stub in `ExScylla.Native` with the same arity, and a
  wrapper here. `sb_use_keyspace/3` is declared in `ExScylla.Native` but has no
  `SessionBuilder` wrapper.
- I/O-bound session operations go through `native_f_async`: the NIF returns `:ok`
  immediately and the Rust `async_elixir!` macro sends `{opaque, result}` to the
  caller; sync variants wait `timeout_ms` (default 5000) then return
  `{:error, :timeout}`.
- Decoded and raw APIs share the same NIFs (`s_query`, `s_execute`, `s_batch`,
  `s_*_paged`); they differ only in Elixir post-processing.
- Statements (`Query`, `Prepared`, `Batch`) are copy-on-write: setters clone the
  Rust struct and return a new reference. Builders (`SessionBuilder`,
  `ExecutionProfileBuilder`, `DefaultPolicyBuilder`, `LatencyAwarenessBuilder`)
  are mutated in place under a `Mutex` and return the same reference.
  `SessionBuilder.build` takes the builder's contents, which leaves a default
  builder in the resource.
- In `Mix.env() == :test`, `ExScylla.Native` compiles the crate with
  `RUSTFLAGS="-C instrument-coverage --cfg scylla_unstable"` and
  `LLVM_PROFILE_FILE=/tmp/instrument_coverage.profraw`.

## Side Effects

- Loads the `ex_scylla` native library at module load (Rustler).
- `SessionBuilder.build` opens TCP connections to ScyllaDB nodes; `Session`
  async calls perform network I/O on the Rust Tokio runtime and deliver results
  as messages to the calling process mailbox.
- Late replies after a sync timeout remain in the caller's mailbox.
- Test builds write LLVM coverage profiles to `/tmp/instrument_coverage.profraw`.
